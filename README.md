# ShopEase

A simple online shopping website built using HTML, CSS and JavaScript.

Live demo: https://danyaramesh1647-lang.github.io/shopease/

## Features
- Product listing with images
- Search products by name
- Filter by category (Clothing, Electronics, Accessories)
- Add to cart, increase/decrease quantity, remove items
- Cart total calculation
- Cart is saved in the browser (localStorage), so it stays after refresh
- Responsive design for mobile and desktop

1. Download or clone the project folder.
2. Open `index.html` in any web browser.
